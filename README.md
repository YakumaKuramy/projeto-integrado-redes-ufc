# 🌐 Projeto Integrado de Redes de Computadores — UFC Quixadá

Repositório dedicado ao desenvolvimento e à documentação do projeto final da disciplina de **Projeto Integrado em Redes de Computadores** da Universidade Federal do Ceará (UFC), Campus Quixadá.

O projeto abrange desde a análise de requisitos de negócios e dimensionamento de tráfego até o projeto físico, documentação em DCIM (NetBox) e validação de topologias em ambiente virtual (PNETLab)[cite: 1, 3, 4, 5].
